# Tipografia — Forte Galpões

**Fonte primária**: [Inter](https://rsms.me/inter/) — fonte variável de código aberto, moderna e altamente legível em todas as escalas.

> Inter é usada exclusivamente como fonte sans-serif da marca.
> Não existe fonte secundária — use os pesos disponíveis para criar hierarquia.

---

## Carregamento via Google Fonts

Adicione no `<head>` do seu HTML:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&display=swap"
  rel="stylesheet"
/>
```

Ou importe via `@fontsource/inter` para self-hosting:
```bash
pnpm add @fontsource-variable/inter
```
```ts
// No main.ts da aplicação
import '@fontsource-variable/inter';
```
