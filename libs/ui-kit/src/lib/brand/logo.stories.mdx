# Logo — Forte Galpões

O logo é composto por um **monograma FG** (badge quadrado em navy com faixa laranja) e um **wordmark** com o nome completo e subtítulo da empresa.

> **Nota de produção**: Os SVGs usam `<text>` com font-stack de fallback.
> Para produção final, exporte os paths tipográficos do Figma.

## Espaço de Proteção

O espaço de proteção mínimo ao redor do logo é equivalente à **altura da letra "F"** no wordmark.
Nenhum elemento visual deve invadir essa área.

```
┌──────────────────────────────────────────┐
│         ← altura do "F"                 │
│  ← "F"  [  LOGO  ]  → "F" →            │
│         ↓ altura do "F"                 │
└──────────────────────────────────────────┘
```

## Uso em HTML / Angular

```html
<!-- Logo horizontal como img tag -->
<img
  src="assets/fg-brand/logo/logo-horizontal.svg"
  alt="Forte Galpões"
  height="48"
  width="240"
/>

<!-- Favicon (adicionar ao <head>) -->
<link rel="icon" type="image/svg+xml" href="assets/fg-brand/favicon/favicon.svg" />
<link rel="apple-touch-icon" href="assets/fg-brand/favicon/apple-touch-icon.svg" />
<link rel="manifest" href="assets/fg-brand/favicon/site.webmanifest" />
```

**Angular `project.json` — assets glob:**

```json
{
  "glob": "**/*",
  "input": "libs/ui-kit/src/lib/brand/assets",
  "output": "assets/fg-brand"
}
```
